# learning-journey

从零开始的编程学习仓库，记录学习笔记与项目代码。

---

## 目录结构

```
learning-journey
├── MySQL/                          # MySQL 数据库学习
│   ├── basic.sql                   # 基础 SQL 练习
│   ├── mall_综合练习.sql            # 商城综合案例
│   ├── MySQL学习笔记.md             # 笔记总览
│   ├── MySQL学习笔记-知识点.md       # 知识点归纳
│   └── MySQL学习笔记-综合练习.md     # 练习笔记
│
└── PyHaven/                        # Python 学习空间
    ├── Base/                       # 编码练习
    │   ├── Python/
    │   │   ├── Base/               # 基础语法（变量、函数、OOP 等）
    │   │   ├── DataStructure/      # 数据结构（链表、栈、队列等）
    │   │   └── Algo/               # LeetCode 题解
    │   ├── DataAna/
    │   │   ├── Numpy/              # NumPy 学习
    │   │   ├── Pandas/             # Pandas 学习与数据集
    │   │   └── Mysql/              # Python 操作 MySQL
    │   └── Practice/               # 综合练习（Jupyter Notebook）
    │
    └── PKBase/                     # 知识库（Obsidian 笔记）
        ├── Python学习笔记.md
        ├── Numpy学习笔记.md
        ├── Pandas学习笔记.md
        ├── 数据结构学习笔记.md
        └── 算法练习笔记.md
```

| 模块 | 技术栈 | 说明 |
